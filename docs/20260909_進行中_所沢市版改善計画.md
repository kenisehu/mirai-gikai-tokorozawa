# みらい議会＠所沢市 改善計画

更新日: 2026-09-10

## 目的

福岡市版・川崎市版・中央区版・沼津版の長所を参考に、所沢市議会の情報を
「見つけやすい・理解しやすい・審議後も追える」形へ段階的に改善する。
独自ドメインの取得は今回の対象外とする。

## 実施順と完了条件

### 1. トップページ軽量化

- 各分野は代表3件まで表示し、残りは分野別一覧へ誘導する
- コンパクト表示にも市民向け見出しを適用する
- スマートフォンで全41件を延々スクロールしなくてよい状態にする

### 2. 41案件の個別見出し

- 公式名称を保持したまま、全案件に短く具体的な見出しを付ける
- 金額、対象施設、変更内容など一次資料で確認できる事実だけを使う
- 通常・詳しい表示で同じ見出しになるようにする

### 3. 訂正受付

- 議案ページから対象議案を引き継ぐ
- 氏名などの個人情報を必須にしない
- 内容、該当箇所、根拠URLを保存し、送信完了を表示する
- 迷惑送信対策と管理者だけが閲覧できる設定を行う

### 4. 予算図解

- 補正予算・決算案件に金額と変更点の要約カードを表示する
- 元資料と単位を明記する
- 数値が確認できない案件では図を出さない

### 5. 審議過程

- 議案ごとに担当委員会、質疑、答弁、採決結果を表示できるデータ構造を追加する
- 公式会議録や審議結果が未公開の場合は、その旨を明示する
- 9月定例会議から順に登録する

### 6. 一般質問

- 令和8年第5回（9月）定例会議の通告を議員・日程・テーマ別に整理する
- 元の通告資料と議会中継へリンクする
- 議案との混同を避けて独立ページにする

### 7. 過去会議の記事化

- 令和8年第4回（6月）、第2回（2月）から着手する
- 議案、公式PDF、審議結果、担当委員会を取り込む
- 市民向け見出しと解説は一次資料との照合後に公開する
- 以後、令和7年分へ広げる

## 作業の分割方針

- 各段階を別コミットにし、検査後すぐ `develop` へ反映する
- この文書のチェック欄と更新日を各段階で更新する
- 長時間の調査結果は `docs/` に残し、会話が区切れても再開できるようにする
- 公式情報が未公表の場合は推測で補わず、次の段階へ進む
